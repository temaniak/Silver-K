# X-Station Web Editor

Локальный веб-редактор звуков встроенного синтезатора и MIDI-шаблонов Novation X-Station. Целевая платформа: Windows 10/11 x64, актуальный Chrome или Edge. USB работает через Web MIDI и установленный MIDI-драйвер устройства.

## Запуск на Windows

Для запуска без сервера распакуйте **`dist/XStation-Web-Portable.zip`** и откройте **`XStationEditor.html`** в Chrome или Edge. Можно передать и один этот HTML: скрипты, стили и демо-патчи уже внутри. Node.js, .NET и интернет для редактирования файлов не нужны. Исходный `web/index.html` предназначен для разработки, а не для открытия двойным кликом.

USB требует разрешения MIDI/SysEx и MIDI-драйвера X-Station. Обмен с устройством через автономный HTML пока не проверен: устройства нет рядом. Доступ к Web MIDI зависит от браузера.

### Дополнительный запуск через localhost

Распакуйте `dist/XStation-Web-Windows-x64.zip` и запустите `XStationWeb.exe`. Откроется Edge, если он установлен, или браузер по умолчанию. При необходимости скопируйте адрес из окна запуска в Chrome/Edge. Оставьте окно запуска открытым.

Устанавливать Node.js, Python или .NET для этого архива не нужно. EXE содержит только локальный веб-сервер и веб-интерфейс. Он не является USB/ASIO-драйвером. Windows EXE собран на macOS; запуск на Windows и аппаратный обмен ещё не проверены.

1. Подключите X-Station по USB и включите питание.
2. На устройстве включите **Play/Synth**, нажмите **Global** дважды, выберите **Synth MIDI Src: USB** и нужный MIDI-канал.
3. В браузере нажмите **Подключить USB**, разрешите MIDI/SysEx, выберите входной и выходной порты X-Station. Установите тот же канал в редакторе.
4. Откройте SYX/ZIP, выберите звук, нажмите **На X-Station**. Звук отправляется во временный буфер. Для постоянного сохранения используйте **Write** на устройстве.
5. **Live MIDI** отправляет изменения параметров. **Синхронизировать ручки** принимает изменения с панели устройства.
6. Для приёма дампа включите **Принимать SysEx**, затем выполните **Dump Current Program / Current Template** в меню устройства.

Звук создаёт сам X-Station. Программной эмуляции синтезатора здесь нет. Флаг **Synth Template** изменяет поведение MIDI-назначений Mod/Env3 и не включает физический режим синтезатора.

## Возможности и границы

- Импорт индивидуальных патчей, банков звуков, MIDI-шаблонов и ZIP-архивов с SYX; экспорт отдельного файла или библиотеки.
- 133 MIDI-параметра: осцилляторы, микшер, фильтр, огибающие, LFO, модуляции, арпеджиатор, режимы голосов.
- 150 назначений шаблона: имя, тип сообщения, канал, CC/NRPN/RPN, диапазон, default, MMC, SysEx с DV; режимы кнопок Normal/Momentary/Toggle/Step.
- Общие настройки Synth Template, производителя и override channel. Прочие поля исходного шаблона сохраняются.
- Отмена изменений, копирование, поиск, тестовые MIDI-ноты, Panic. Файлы обрабатываются в браузере и не отправляются на внешний сервер.

**Офлайн-карта параметров звуков экспериментальная.** CC/NRPN взяты из официальной MIDI-таблицы. Смещения внутри патча предполагают общую структуру с KS; диапазоны проверены на всех 100 индивидуальных X-Station патчах. Это не доказывает соответствие каждого поля на реальном устройстве. Имя патча и формат MIDI-шаблонов подтверждены отдельно. Эффекты X-Station не заявлены как поддерживаемые live-параметры.

Формат 8208-байтовых шаблонов поддерживается. Другие форматы, в том числе короткие synth-template дампы из OS-архива, и обновления прошивки не редактируются. Автоматический запрос текущего патча не восстановлен; поддерживается приём вручную инициированного дампа. Общие настройки маршрутизации портов сохраняются без редактора этих полей.

После редактирования сохраняйте SYX перед закрытием страницы. Постоянного хранения библиотеки в браузере нет. Браузер может требовать подтверждение нескольких загрузок, если сохранять много файлов.

## Проверка

24 теста проверяют точное сохранение данных, неизвестные поля, packed-параметры, SysEx/DV, временный synth-буфер, приём фрагментов, каналы, закрытие MIDI-портов и остановку нот. MIDI-транспорт проверен на фиктивных портах, аппаратная проверка не проводилась.

Через Codex IAB проверены импорт исходного архива с 70 шаблонами, поиск, изменение осциллятора и отмена, изменение CC в шаблоне и скачивание настоящего SYX. Скачанный файл повторно разобран: 8208 байт, CC105, остальные поля сохранены. Проверены экраны 1536×948 и 390×844, без ошибок приложения в консоли. Производственная сборка и Windows x64 EXE собраны.

## Для разработки и самостоятельного размещения

```sh
cd web
npm ci
npm test
npm run dev
npm run build
```

Дополнительная проверка ваших исходных файлов:

```sh
XSTATION_FIXTURES=/path/to/extracted/archives npm test
```

`npm run build` также создаёт автономный `dist/XStationEditor.html` без внешних ресурсов. Сборка и тесты проходят; проверка прямого открытия через `file://` инструментом браузера недоступна из-за его политики URL. Проверка на Windows и реальном устройстве ещё нужна.

`web/build/` — статические файлы для веб-размещения через HTTPS или localhost.

Windows-запуск после сборки веб-части:

```sh
dotnet publish launcher/XStation.Web.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None -o dist/windows
```

Демонстрационные SYX взяты из предоставленных пользователем оригинальных архивов Novation. Они сохранены без изменений; исходные архивы не изменялись. Это независимая реконструкция, не официальный редактор Novation.

Доказательства и ограничения: [template-protocol.md](docs/template-protocol.md), [synth-protocol.md](docs/synth-protocol.md).
