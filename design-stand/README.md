# Silver-K — отдельный дизайн-стенд

Локальный стенд для доработки выбранного скина перед переносом в основной плагин/приложение. В нём нет DSP, звукового движка, загрузки прошивок, MIDI, ROM или связи с основным приложением.

## Что работает

- Режимы KS и K-Station: светлая/тёмная нижняя панель, доступные формы и разное наполнение Extra.
- Все основные ручки, ADSR, меню и LED-переключатели меняют локальные значения.
- Отдельные значения для партий, моделей, источников PWM и LFO 1/2.
- В K-Station оба LFO показаны одновременно в колонках: Rate над Delay, Wave/Sync снизу. В KS выбор LFO находится в шапке, Wave — внизу слева.
- Настройки голоса перенесены из Volume в Options вверху Program.
- Все дополнительные настройки помещаются в своих блоках без прокрутки: мини-кнобы с числами справа в Arp/Options, ползунки в остальных Extra и меню в колонках. PW Position / LFO2 PWM / Env PWM доступны на основной панели и не дублируются в Extra.
- Extra заменяет соответствующий блок; две огибающие используют одну общую Extra. FM открывается между OSC 2 и OSC 3.
- Эффекты выбираются меню; шесть позиций ручек, Mod Wheel Delay/Chorus на основной панели. Chorus Type/Sync/Sync Start расположены в нижнем ряду; Extra больше не нужна. Неиспользуемые позиции у эффектов с меньшим числом параметров приглушены.
- Volume/Arp/Glide объединены: Glide и Tempo сверху, Volume и Gate Length снизу; Volume выделена синим градиентным фоном; KS Rhythm выведен в меню. Между всеми внешними модулями одинаковый зазор 6 px, без пересечений. Effects равен Filter по ширине. Под LCD работают Previous/Next для перебора демонстрационных названий.
- Осцилляторы и основные огибающие оформлены цельными панелями с внутренними линиями.
- В Arp/Options используются маленькие чёрные ребристые ручки с белой меткой в стиле Volca/Eurorack.
- Sync/FM и внутренние линии подняты к середине между предыдущим рядом ручек и следующим заголовком; они остаются видимыми и доступными даже при открытой Extra осциллятора.
- Масштаб, показ сетки и наложение утверждённого макета для проверки расположения.

Ручки: вертикальное перетаскивание, колесо и стрелки. Shift при перетаскивании даёт точную настройку; Shift со стрелками меняет по 10. Home/End — границы, двойной клик — значение по умолчанию. Число под ручкой можно вводить напрямую.

Все значения хранятся только в памяти страницы. Patch browser показывает демонстрационные названия и не загружает настоящие патчи. Panic используется для проверки состояния интерфейса.

## Локальный запуск

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

Открыть `http://127.0.0.1:4173/`. Сервер запущен в текущем сеансе.

## Файлы

- `src/App.jsx` — компоновка и локальное поведение.
- `src/controls.jsx` — ручки, меню, LED и ADSR.
- `src/styles.css` — геометрия, сетка и режимы оформления.
- `src/catalog.json` — статические описания контролов K/KS из исходников проекта; не исполняют код синтезатора.
- `public/assets/` — отдельные растровые изображения ручки, LED и фейдеров.
- `public/reference.png` — выбранный макет.

Основные исходники плагина восстановлены. Предыдущая незавершённая попытка интеграции сохранена в `../build/design-stand-integration-wip/`; не использовать её как готовый скин. Перенос утверждённого дизайна выполняется отдельным шагом.
