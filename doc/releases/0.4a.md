# Silver-K 0.4a

Windows x64: VST3 and Standalone. macOS Apple Silicon: AU, VST3 and Standalone. Plugin version: 0.4.0.

Updated October 19, 2026: rebuilt both platform packages with NK Stuff as the displayed manufacturer. AU identifiers, VST3 class IDs and existing data paths are preserved. README now credits Gearmulator's open-source code.

- Bipolar knobs now use centre-zero LED arcs. Values appear temporarily in place of captions; click a caption for numeric entry. Envelope values remain visible.
- Oscillator controls have been reordered. PW selectors sit above their knob and update its caption. Extra buttons are compact O buttons; LFO headings identify the selected LFO.
- Program Options now selects Host, Internal or MIDI Clock. The choice is stored with the session.
- Patch-source removal clears cached entries across reopening. Explicit Rescan restores removed paths inside Patches. ZIP and extracted copies are deduplicated without hiding different sounds with the same name.
- KS requires user program data: one complete MIDI file, a compatible MIDI set or full user Flash. Automatic Silver Init startup data has been removed. The required zero Wave ROM is retained.
- Required assets are managed in ROMs; additional libraries use Patches; custom skins use Skins. Selected external assets are copied without removing originals.
- Expanded hardware controls, KS part and Drum Map workflows, Drum Edit, project restoration and persistent browser settings. Drum selection responds without reloading the complete map before every note.
- Stable KS C++ compatibility controller and worker transport/control improvements. The original H8 remains a test reference; the complete semantic controller migration remains unfinished. Windows Release VST3 uses non-incremental linking.
- Added performance diagnostics, safer host-latency updates, a shorter README and a plugin user guide.

Firmware and original sound data are not included. A zero Wave ROM does not reproduce sampled sounds. KS external audio input is not implemented. macOS bundles are ad hoc signed and not notarized. Performance and latency remain under development.
