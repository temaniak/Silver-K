# Silver-K 0.4.5a — release candidate

- Combine the native C++ K-Station and KS controllers in one product build.
- Enable external audio input for K and KS in Standalone, VST3 and AU. Mono
  and stereo inputs are supported; stereo is mixed to the hardware mono input.
- Route KS external input to both its effects and voice DSPs. Auxiliary audio
  outputs no longer feed back into the voice DSP input.
- Clear KS warm-up notes after restoring the program, before audio starts.
- Keep the existing Silver-K skin and plugin identifiers.

In Standalone, choose your input in Options → Audio/MIDI Settings and clear
Mute audio input. In a DAW, enable and route the Vocoder / external input.
Use External input level for the filter/envelope path, Direct to effects for
processing without held notes, or Vocoder with a played carrier sound.

This is a development candidate. Publication awaits final platform and DAW
validation. Firmware and sound data are not included.
