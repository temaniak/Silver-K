# Silver-K 0.4.4a

Windows x64: VST3 and Standalone. macOS Universal 2: AU, VST3 and Standalone for Apple Silicon and Intel. Plugin version: 0.4.4.

- Reduced K-Station arpeggiator timing variation under streams of repeated identical filter-cutoff MIDI CC messages. Changed cutoff values and other MIDI messages are preserved.
- Fixed macOS VST3 Prefetch rendering, preventing missing audio when a host requests audio faster than realtime.
- Removed diagnostic logging that could allocate memory in the audio callback during resampler padding. DSP calculations, buffer sizes and thread priorities are unchanged.

Verified in REAPER on Apple Silicon at 48 kHz / 256 samples. Startup transients remain; this does not establish Windows DAW or physical Intel realtime performance. macOS bundles are ad hoc signed and not notarized.
