# Silver-K 0.4.2a

Windows x64: VST3 and Standalone. macOS Universal 2: AU, VST3 and Standalone for Apple Silicon and Intel. Plugin version: 0.4.2.

- Fixed V-Station FXB banks being rejected when the outer file size is stale or extra data follows a complete bank chunk. The importer validates the internal sound and name tables before loading the bank.
- Added support for V-Station version 2 bank chunks with their different sound and name offsets. Original sound parameters, names, slot order and bank addresses are preserved.
- Added support for named V-Station MIDI and SysEx presets, including exports whose MIDI event length omits the name. Presets load directly from the original files and retain their V-Station identity. Individual User-number presets remain visible as ordinary presets.
- Updated the import cache so connected sources are refreshed automatically after upgrading, while retaining favourites for unchanged presets. Added regression coverage for both bank layouts, named MIDI/SysEx, cache migration and malformed or truncated inputs.
- Added macOS Universal 2 builds for the plugins, Standalone and Wave ROM Builder. Fixed deployment-target initialization, including empty older CMake caches, so the intended macOS 12.0 minimum is applied before compiler detection.
- Added architecture and minimum-macOS checks to packaging, including Wave ROM Builder. Package manifests record the verified compatibility information. Updated the builder source package and build/install documentation.
- Added macOS build, test and packaging workflows for Apple Silicon and Intel runners.
- Updated the firmware-backed Performance UI check to follow the current mixer layout.

AU/VST3 identifiers and existing data paths are preserved. Existing synthesis and preset-conversion rules are unchanged.

Both desktop packages include Wave ROM Builder, the Silver Flat skin, documentation, corresponding source, licences and SHA-256 checksums. Firmware and original sound data are not included. KS requires a compatible firmware BIN, Wave ROM and complete program/performance data.

macOS bundles target macOS 12.0 or later and are ad hoc signed, not notarized. Older macOS versions and different host applications may require separate runtime validation. Alpha; performance and latency remain under development.
