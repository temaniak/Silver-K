# Silver-K 0.5 Alpha

- New native C++ controllers for K-Station and KS.
- External audio input in Standalone, VST3 and AU, with filter/envelope, effects and vocoder processing.
- The existing interface and plugin identifiers are retained.

In Standalone, select your input in Options → Audio/MIDI Settings and clear Mute audio input. In a DAW, enable and route the Vocoder / external input. Mono and stereo inputs are supported; stereo is mixed to the instrument's mono input.

Windows x64: Standalone and VST3. macOS Universal 2: Standalone, VST3 and AU.

Firmware and original sound data are not included.
