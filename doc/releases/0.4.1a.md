# Silver-K 0.4.1a

Windows x64: VST3 and Standalone. macOS Apple Silicon: AU, VST3 and Standalone. Plugin version: 0.4.1.

- Improved Windows knob and button graphics at small interface sizes and different DPI settings. Filtered artwork is cached for reuse.
- Fixed the Size menu opening near the screen edge instead of the right-click position. Custom sizing remains available from 50 to 150 percent.
- Fixed the ellipsis and dashes in menus, dialogs, tooltips and LFO headings.
- Added skin packages with editable layouts, colours, fonts and artwork. Setup provides Load skin, Reload, Export template and Skins folder; F5 reloads the active package. Invalid packages retain the working interface.
- Included the Silver Flat skin and a skin-authoring guide. The same skin files work on Windows and macOS.
- Included the Wave ROM Builder companion and its guide under Tools.

AU/VST3 identifiers and existing data paths are preserved. Skin changes affect the interface only.

Firmware and original sound data are not included. KS requires a compatible firmware BIN, Wave ROM and complete program/performance data. macOS bundles are ad hoc signed and not notarized. Alpha; performance and latency remain under development.
