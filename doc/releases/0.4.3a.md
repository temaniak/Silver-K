# Silver-K 0.4.3a

Windows x64: VST3 and Standalone. macOS Universal 2: AU, VST3 and Standalone for Apple Silicon and Intel. Plugin version: 0.4.3.

- Added an experimental KS two-core processing checkbox in Setup for Windows and macOS. It can be switched without reloading firmware, and the choice is saved in preferences and project state.
- Performance improvement is not guaranteed; total CPU usage may increase. The option is off by default and applies to KS only.
