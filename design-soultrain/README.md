# SoulTrain interface

Approved Silver-K interface by SoulTrain, adapted for K-Station and KS. Source is retained here as a design checkpoint; native integration follows in a separate commit.

Original author assets, Inter and Pixelmix fonts are included locally. No firmware, banks, captures or internal reports are part of this interface.

Use `npm ci` and `npm run dev -- --host 127.0.0.1 --port 4173`.
