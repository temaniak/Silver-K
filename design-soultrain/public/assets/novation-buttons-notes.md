# Novation-inspired selector caps

Created with built-in Image Gen, 2026-10-15. Inspired by the low black oval pushbuttons visible in K-Station/KS Rack front panels, rather than an exact branded reproduction. The original units use separate LEDs; lighting the entire ruby-red cap is the user's requested adaptation.
Reference inspected: https://medias.audiofanzine.com/images/normal/novation-ks-rack-6467901.jpg

Off prompt: one low-profile black oval molded rubber pushbutton, top-down orthographic, width:height 2.4:1, subtle bevel/grain, dark seat, fixed upper-left soft light, transparent background, no text/logo/LED, tight wide canvas.
On edit prompt: preserve exact off asset shape/position/texture/seat and fixed lighting, change only cap to internally backlit ruby red translucent rubber, dark edges, no separate LED, no neon aura.

Consuming components: ButtonCap / Lamps in src/controls.jsx, FM seam in App.jsx, Performance and part power in Performance.jsx. CSS renders the cap at 26 × 11 logical pixels (22 × 10 in compact Arp modes). Source PNG alpha is preserved.
