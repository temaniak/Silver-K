Silver-K 0.8.5b
===============

Changes since 0.8b
-----------------

- In Host mode, the K-Station and KS arpeggiators respond to live MIDI at the
  project tempo while the DAW transport is stopped. On Play, they align with
  the DAW grid. The internal Tempo is used until the host supplies a BPM value.
  K-Station now plays the first step for notes placed exactly on the grid
  with either Key Sync setting.
- The manual Control MIDI channel setting has been removed. The panel follows
  the MIDI channel of the active firmware or the KS Performance part being
  edited. Knob and slider values no longer revert when editing a loaded preset
  with a mismatched channel. Incoming MIDI retains its channel in both the
  plug-in and Standalone.
- Browser → Rescan rebuilds the list from available folders and banks.
  Removed sources disappear and new ones are added. Manually connected
  libraries are included. The list refreshes even when the old cache is locked.
- Slider thumbs are easier to grab near either end of their travel. Knobs
  respond immediately when you reverse direction after reaching a limit.
  Fixed knob dragging at the screen edge on macOS.
- On Windows, the selected Software or OpenGL renderer is restored when
  reopening the editor or reloading the plug-in.
- SoulTrain buttons now use the same shadow as the combo boxes. The visible
  gaps in the main menu, Parts, Effects, and Voicing, and between Seq and
  Drum Edit, are 2 px at 100% scale. The interface footer shows the current version.

Packages
--------

Windows x64 includes VST3 and Standalone. macOS Universal 2 includes AU, VST3,
and Standalone for Apple Silicon and Intel.

See INSTALL_EN.txt and USER_GUIDE_EN.txt for installation and usage. Russian
versions are included in the same package.
