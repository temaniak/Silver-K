Silver-K 0.8.5b user guide
==========================

First launch and data folders
-----------------------------

1. Open Silver-K on an instrument track in your DAW or start the Standalone app.
2. Use Setup → Choose Silver-K folder… to choose a permanent location for your data. The
   default is Documents/Silver-K. Silver-K creates the subfolders for you.
3. Place the files as shown below, choose Setup → Rescan folders, then select the detected
   K-Station or KS firmware in Setup. Wait for loading to finish.
4. In a DAW, route MIDI to the Silver-K track and enable monitoring. In Standalone, select
   your audio output and MIDI input under Options → Audio/MIDI Settings.

Silver-K/ROMs
  K-Station 2.1.01 or KS 2.1.02 firmware. For KS, also put the extracted KS All Data MIDI
  file and, if you have one, a compatible Wave ROM here.

Silver-K/Patches
  Additional banks and individual presets. You can use subfolders and supported ZIP
  archives.

Silver-K/Patches/User
  User presets in .silver-k format. Save current saves here. You can also copy .silver-k
  files received from other users to this folder.

Silver-K/Skins
  Additional skins, with each skin in its own subfolder. After rescanning, choose one
  under Setup → Skin.

When moving a project to another computer, keep its firmware, KS Data, and Wave ROM
available. When you select a different Silver-K folder, Silver-K scans the new location.
Move the underlying files yourself if needed.

KS All Data

KS All Data is the factory dump of programs and Performances in a MIDI file. Silver-K
reads it when starting KS. K-Station uses its own firmware and needs no KS data.

1. Open the archive containing KS All Data.
2. Extract the complete factory MIDI file with the .mid or .midi extension.
3. Copy the extracted MIDI file directly into Silver-K/ROMs, alongside the firmware. You
   can store the archive separately.
4. Choose Setup → Rescan folders. Once the data is found, select the KS firmware. If Setup
   shows KS Data: missing, check the selected Silver-K folder and make sure its ROMs
   folder contains the extracted file with programs and Performances.

Zero Wave ROM

The firmware runs KS, KS All Data provides the factory sound settings, and the Wave ROM
contains the sampled wave data. KS uses all three components.

ks-wave-zero.bin is a 129,024-byte file filled with zeros. It provides Wave ROM memory so
KS can start and play sounds generated by its own synthesis engine. Silver-K creates the
file in ROMs if a compatible Wave ROM is absent. A copy of the zero ROM is included in the
package.

With the zero ROM loaded, any sampled wave used by a preset or drum sound is silent. A
sound that combines synthesis and samples may sound incomplete. A sample-only sound may be
silent. To hear those waves, add a compatible Wave ROM containing sampled wave data to
ROMs and choose Rescan folders. Silver-K gives it priority over the zero ROM. Keep the
factory MIDI from KS All Data in ROMs in either case.

Preset browser
--------------

1. Open Browser. Silver-K scans your Patches folder automatically. Use Add file… to
   connect a preset or bank, or Add folder… to connect a library and its subfolders.
   Supported formats include Silver-K, SysEx .syx, MIDI containing patch dumps, compatible
   V-Station .fxb banks and .fxp presets, and supported ZIP archives.
2. Use Search patches to search names, tags, models, and other metadata. Instrument,
   Source, Filter tags, and KS bank narrow the list. Use Columns to show or hide columns.
   Click a header to sort, and drag its border to change the column width.
3. Click a preset name to load it. In KS Performance, select the part first when loading
   an individual sound. Loading a full Performance restores all the parts. The preset
   arrows in the top bar follow the current browser list.
4. Double-click a Source cell to open its location in Finder or File Explorer. Rescan
   refreshes connected libraries. Remove source removes the selected source from the list
   and leaves its files on disk.

Source → User shows your presets and four starting templates: Init K-Station, Init KS,
Init Drum Map, and Init Performance. Factory Init Program and Init Performance entries are
hidden by default. Show init brings them back into the list. Drum Maps remain available.

To edit tags, double-click a Tags cell. Separate tags with commas. The browser suggests
existing tags as you type. Press Enter to save or Esc to cancel. Use the star to mark a
favourite, and Show only favourites to display starred presets.

Saving and sharing

- Save current… creates a .silver-k preset in Patches/User. In KS Performance, choose Save
  selected part… for the current part or Save Performance… for the entire Performance.
- Compatible standard presets can be exported as SysEx .syx.
- KS+ marks a preset that contains a user Drum SEQ. Use Export .silver-k… to export the
  entire preset with its sequence and settings. KS+ presets require Silver-K.

Drum SEQ in KS
--------------

Getting started

1. Load a Drum Map in KS. In Performance, select the part containing the Drum Map.
2. On Main, open the gear in the Arpeggiator section, enable on/off, select Drum mode, and
   choose Rhythm → SEQ. Factory rhythms 1–33 are available in the same menu.
3. Click Seq and choose sequence 1–12 along the bottom of the editor. Play a MIDI note to
   start it. The active sequence and the playing step column light up.

Use Drum Edit to edit the drum sound itself. With a Drum Map loaded, enable Drum Edit and
play a note. The display shows the note and drum name, the controls switch to that sound,
and the note auditions it.

Editing the grid

Each sequence has 10 rows and up to 16 steps. On the left, choose a sound from the current
Drum Map for each row using its name and MIDI note. Steps sets the loop length from 1 to
16. Shortening the loop preserves the steps beyond its end. They play again when you
extend it.

- Click an empty cell to add a hit. Click a filled cell to select it for editing.
  Double-click it or use × beside the parameter menu to remove the hit.
- Velocity sets the hit strength from 1 to 127. The cell fills from the bottom up. Drag up
  or down on the cell to change its velocity directly.
- Probability sets the chance of playing the hit on each pass, from 0 to 100%. A
  successful hit plays with all its repeats.
- Ratchet sets 1 to 16 evenly spaced hits within a single step.

The menu beside the value selects the parameter edited by the slider. Every hit stores all
three values.

Note ranges and sequence switching

- With Assigned Keys off, any note received by the part plays the sequence selected in the
  editor.
- With Assigned Keys on, set Low note and High note for each sequence you use. Both limits
  are inclusive. For example, C1–D2 assigns a range and C1–C1 assigns a single key. Open
  the note menu and play a note to set that limit from your keyboard. If you have one
  programmed sequence with no assigned range, it is available across the part's keyboard
  range.
- Switch timing controls when a different sequence takes over. Immediate switches at the
  next boundary determined by the current sync settings. End of sequence waits for the
  current sequence to finish. After step 1–16 waits until the selected step of the current
  sequence finishes. If that step is beyond the loop length, the switch happens at the end
  of the loop.
- With Key Sync on, Retrigger controls what happens when you press another key assigned to
  the same sequence. Enable it to restart from the first step. Disable it to keep the
  current step while playing within the same range. A note assigned to a different
  sequence follows Switch timing. Further notes in that range keep the scheduled switch.
- Latch in the Arpeggiator keeps the rhythm going after you release the keys. With Latch
  off, releasing the last note stops the sequence and the next note starts it again. Use
  Latch On together with Retrigger Off to play over a continuous rhythm.

Each part's grids, note assignments, and playback settings are saved in the DAW project.
To move the sound and its rhythm into another project, use Save current… to save a KS+
preset.

Clock source and Performance
----------------------------

Setup → Clock source sets the tempo source for the entire Silver-K instance. In Host mode,
play the arpeggiator from your keyboard at the project tempo while the DAW is stopped.
During playback, the arpeggio follows the DAW grid. Silver-K keeps the last BPM received
from the DAW and uses the synth's Tempo until the DAW supplies one. Internal uses the
synth's Tempo, and MIDI follows incoming MIDI Clock. Arp Sync sets the note division of
the melodic arpeggiator. Factory drum rhythms and Drum SEQ use their own step grid.

In KS, enable Performance in the top bar and open Perf to set up to four parts. Check each
part's enabled state, MIDI channel, Low note / High note, and output. If you choose Aux
3+4, enable the instrument's additional output in your DAW.

Setup → Audio buffer profile changes the audio reserve inside Silver-K. A larger reserve
can reduce dropouts and adds latency. Set your audio device's buffer size in your DAW or
Standalone. KS: two CPU cores · experimental applies to KS, is off by default, and can
affect CPU load depending on your computer and preset.

External audio input
--------------------

External audio input is available in Standalone, VST3, and AU.

- In Standalone, select an input under Options → Audio/MIDI Settings and clear Mute audio
  input when you are ready to listen.
- In a DAW, route audio from an audio track to the instrument's Vocoder / external input.
  Your host may show it as Side Chain.

Stereo input is summed to mono in all formats.

Raise the external input level in the Mixer settings. Hold MIDI notes to pass the signal
through the filter and envelope. Direct to FX sends the input to the effects. To use the
vocoder, select Vocoder and play a note. In KS Performance, the vocoder belongs to Part 1.
