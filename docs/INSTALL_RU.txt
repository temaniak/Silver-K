Установка Silver-K 0.8b
=======================

macOS
-----

Сборка Universal 2 содержит версии для Apple Silicon и Intel. Целевая версия системы —
macOS 12.0 и новее. Для AU и VST3 нужен 64-разрядный хост.

1. Распакуйте архив и закройте DAW.
2. Скопируйте весь пакет Silver-K.component в /Library/Audio/Plug-Ins/Components/. Для
   новой установки VST3 используйте /Library/Audio/Plug-Ins/VST3/. При обновлении замените
   Silver-K.vst3 в папке, из которой его загружал хост.
3. Переместите Standalone Silver-K.app в «Программы» или другую постоянную папку.
4. Запустите DAW, обновите список плагинов и откройте Silver-K на инструментальной
   дорожке. В списках хоста производитель указан как NK Stuff.

При обновлении сохраните прежний AU и его возможный дубликат из
~/Library/Audio/Plug-Ins/Components/ вне папок сканирования. Для работы достаточно одного
активного компонента в системной папке. Если macOS блокирует запуск проверенной сборки,
разрешите запуск конкретного приложения в настройках «Конфиденциальность и безопасность».

Windows x64
-----------

1. Распакуйте архив в постоянную папку и закройте DAW.
2. Скопируйте весь пакет Silver-K.vst3 в C:\Program Files\Common Files\VST3\.
3. Для работы без DAW запустите Silver-K.exe из папки Standalone.
4. Запустите DAW, обновите список плагинов и откройте Silver-K на инструментальной
   дорожке.

Если Windows сообщает об отсутствующей библиотеке Visual C++, установите пакет Microsoft
Visual C++ Redistributable для x64.

Данные синтезатора
------------------

При первом запуске выберите папку Silver-K в Setup. Для K-Station положите его прошивку в
ROMs. Для KS положите в ROMs прошивку и MIDI-файл, извлечённый из архива KS All Data. В
эту же папку можно добавить совместимый Wave ROM с сэмплами. При его отсутствии Silver-K
создаст пустой ks-wave-zero.bin.

Дополнительные библиотеки поместите в Patches, скины — в Skins. Нажмите Setup → Rescan
folders, затем выберите модель. Прошивка, оригинальные заводские звуки и сэмплы
добавляются из ваших файлов.
