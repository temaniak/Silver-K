Руководство по Silver-K 0.8b
============================

Первый запуск и папки
---------------------

1. Откройте Silver-K на инструментальной дорожке DAW или запустите Standalone.
2. В Setup → Choose Silver-K folder… выберите постоянную папку для данных. По умолчанию
   это Документы/Silver-K. Silver-K создаст в ней подпапки.
3. Разложите файлы по таблице, нажмите Setup → Rescan folders и выберите обнаруженную
   прошивку K-Station или KS в Setup. Дождитесь завершения загрузки.
4. В DAW направьте MIDI на дорожку с Silver-K и включите её мониторинг. В Standalone
   выберите аудиовыход и MIDI-вход в Options → Audio/MIDI Settings.

Silver-K/ROMs
  Прошивку K-Station 2.1.01 или KS 2.1.02. Для KS сюда же положите извлечённый MIDI-файл
  KS All Data и, если он у вас есть, совместимый Wave ROM.

Silver-K/Patches
  Дополнительные банки и отдельные пресеты. Можно использовать подпапки и поддерживаемые
  ZIP-архивы.

Silver-K/Patches/User
  Пользовательские пресеты .silver-k. Сюда сохраняет Save current. В эту же папку можно
  положить полученный от другого пользователя файл .silver-k.

Silver-K/Skins
  Дополнительные скины, каждый в своей подпапке. После сканирования выберите его через
  Setup → Skin.

При переносе проекта на другой компьютер сохраните доступ к его прошивке, KS Data и Wave
ROM. При выборе другой папки Silver-K сканирует новое расположение, а перенос файлов
выполняется вручную.

KS All Data

KS All Data — заводской дамп программ и Performance в MIDI-файле. Silver-K использует его
при запуске KS. Для K-Station достаточно его собственной прошивки.

1. Откройте архив, в котором находится KS All Data.
2. Извлеките полный заводской файл MIDI с расширением .mid или .midi.
3. Скопируйте извлечённый MIDI-файл непосредственно в Silver-K/ROMs рядом с прошивкой. Сам
   архив можно хранить отдельно.
4. Нажмите Setup → Rescan folders. После обнаружения данных выберите прошивку KS. Если в
   Setup указано KS Data: missing, проверьте, что открыли правильную папку Silver-K и что
   в ROMs лежит извлечённый файл с программами и Performance.

Zero Wave ROM

Прошивка запускает KS, KS All Data даёт заводские настройки звуков, а Wave ROM содержит
данные сэмплированных волн. Это три разных компонента.

ks-wave-zero.bin — файл из нулей размером 129 024 байта. Он заполняет память Wave ROM,
чтобы KS мог запуститься и играть звуки, которые синтезирует сам. Silver-K создаёт такой
файл в ROMs автоматически, когда совместимый Wave ROM отсутствует. Готовый нулевой файл
также находится в комплекте.

Если пресет или барабан обращается к сэмплированной волне, эта составляющая при нулевом
ROM будет беззвучной. Поэтому некоторые звуки будут неполными, а полностью сэмплированный
звук может молчать. Чтобы эти волны зазвучали, положите совместимый Wave ROM с данными в
ROMs и нажмите Rescan folders. При сканировании Silver-K отдаёт ему приоритет перед
нулевым ROM. Заводской MIDI из KS All Data нужен в обоих случаях.

Браузер пресетов
----------------

1. Откройте Browser. Папка Patches подключается автоматически. Через Add file… можно
   подключить отдельный пресет или банк, через Add folder… — библиотеку с подпапками.
   Поддерживаются Silver-K, SysEx .syx, MIDI с дампом патчей, совместимые банки и пресеты
   V-Station .fxb и .fxp, а также поддерживаемые ZIP-архивы.
2. Используйте Search patches для поиска по названию, тегам, модели и другим метаданным.
   Instrument, Source, Filter tags и KS bank помогают сузить список. Columns показывает и
   скрывает колонки. Нажмите заголовок для сортировки и перетащите его границу, чтобы
   изменить ширину колонки.
3. Щёлкните по имени пресета, чтобы загрузить его. В KS Performance сначала выберите
   партию, если загружаете отдельный звук. Полный Performance восстанавливает все партии.
   Стрелки переключения пресетов в верхней панели следуют текущему списку браузера.
4. Двойной щелчок по ячейке Source открывает расположение источника в Finder или
   Проводнике. Rescan повторно сканирует подключённые библиотеки. Remove source исключает
   выбранный источник из списка, сохраняя его файлы на диске.

Source → User показывает ваши пресеты и четыре стартовых шаблона — Init K-Station, Init
KS, Init Drum Map и Init Performance. Заводские Init Program и Init Performance скрыты по
умолчанию. Show init возвращает их в список. Карты ударных остаются доступны.

Чтобы изменить теги, дважды щёлкните по ячейке Tags. Вводите теги через запятую. Браузер
предлагает уже известные варианты по первым буквам. Enter сохраняет правку, Esc её
отменяет. Звезда помечает избранное, а Show only favourites показывает только отмеченные
пресеты.

Сохранение и обмен

- Save current… создаёт пресет .silver-k в Patches/User. В KS Performance выберите Save
  selected part… для текущей партии или Save Performance… для всего Performance.
- Совместимые стандартные патчи можно экспортировать как SysEx .syx.
- KS+ означает, что пресет содержит пользовательский Drum SEQ. Команда Export .silver-k…
  экспортирует его целиком вместе с секвенцией и её настройками. Для загрузки KS+ нужен
  Silver-K.

Drum SEQ в KS
-------------

Запуск

1. Загрузите Drum Map в KS. В Performance выберите партию, в которую загружена карта.
2. На Main откройте шестерёнку в секции Arpeggiator, включите on/off, выберите режим Drum
   и установите Rhythm → SEQ. В этом меню также доступны заводские ритмы 1–33.
3. Нажмите появившуюся кнопку Seq. Выберите секвенцию 1–12 внизу окна и запустите её
   MIDI-нотой. Во время игры подсвечиваются активная секвенция и звучащий столбец.

Drum Edit открывает редактирование самого барабанного звука. При загруженной карте ударных
включите Drum Edit и сыграйте ноту. На экране появятся нота и название барабана, ручки
переключатся на его параметры, а звук можно сразу прослушать.

Сетка

В каждой секвенции 10 строк и до 16 шагов. Слева в каждой строке выберите барабан по имени
и MIDI-ноте из текущей карты. Steps задаёт длину цикла от 1 до 16 шагов. При уменьшении
длины шаги за границей сохраняются и снова звучат, если удлинить цикл.

- Один щелчок по пустой клетке ставит удар. Щелчок по заполненной клетке выделяет её для
  редактирования. Двойной щелчок или × рядом с меню параметров удаляет удар.
- Velocity задаёт силу удара от 1 до 127. Она видна по заполнению клетки снизу вверх.
  Чтобы изменить её прямо в сетке, перетащите мышь вверх или вниз по клетке.
- Probability задаёт вероятность удара от 0 до 100% при каждом проходе. При срабатывании
  проигрывается удар со всеми его повторами.
- Ratchet задаёт от 1 до 16 равномерных ударов внутри одного шага.

Меню рядом со значением выбирает, какой параметр редактирует ползунок. Все три значения
хранятся у каждого удара.

Ноты и переключение секвенций

- С выключенным Assigned Keys любая нота, которую получает партия, играет секвенцию,
  выбранную в окне.
- С включённым Assigned Keys задайте для каждой используемой секвенции Low note и High
  note. Обе границы входят в диапазон. Например, C1–D2 назначает секвенцию на диапазон, а
  C1–C1 оставляет одну клавишу. Чтобы задать границу с клавиатуры, откройте её меню и
  сыграйте ноту. Если запрограммирована одна секвенция и её диапазон не задан, она
  доступна на всей клавиатуре партии.
- Switch timing задаёт переход к другой секвенции. Immediate выполняет переход на
  ближайшей границе по текущей синхронизации. End of sequence ждёт завершения текущей
  секвенции. After step 1–16 ждёт выбранного шага текущей секвенции. Если цикл короче
  выбранного шага, переход происходит на его конце.
- При включённом Key Sync настройка Retrigger управляет повторным нажатием в диапазоне той
  же секвенции. Включите её для перезапуска с первого шага. Выключите, чтобы сохранить
  текущий шаг при игре по тому же диапазону. При нажатии клавиши другой секвенции
  действует Switch timing. Повторное нажатие в её диапазоне сохраняет запланированный
  переход.
- Latch в Arpeggiator продолжает ритм после отпускания клавиш. При выключенном Latch
  отпускание последней ноты останавливает секвенцию, и следующая нота запускает её заново.
  Для игры поверх непрерывного ритма подойдёт Latch On вместе с Retrigger Off.

Сетки, назначения нот и параметры воспроизведения сохраняются отдельно для каждой партии в
проекте DAW. Чтобы перенести звук вместе с ритмом в другой проект, сохраните его через
Save current… как KS+.

Clock source и Performance
--------------------------

Setup → Clock source задаёт источник темпа для всего экземпляра Silver-K. Host следует
темпу и транспорту DAW. Internal использует внутренний Tempo, MIDI следует входящему MIDI
Clock. При одном и том же BPM Arp Sync задаёт деление мелодического арпеджиатора.
Заводские барабанные ритмы и Drum SEQ используют свою сетку шагов.

В KS включите Performance в верхней панели и откройте Perf, чтобы настроить до четырёх
партий. Проверьте включение партии, её MIDI-канал, диапазон Low note / High note и выход.
При выборе Aux 3+4 включите дополнительный выход инструмента в DAW.

Setup → Audio buffer profile меняет резерв аудио внутри Silver-K. Увеличенный резерв может
уменьшить выпадения звука, добавляя задержку. Размер буфера аудиоустройства задаётся в DAW
или Standalone. Опция KS: two CPU cores · experimental относится к KS, по умолчанию
выключена и может изменить нагрузку в зависимости от компьютера и пресета.

Внешний аудиовход
-----------------

Внешний аудиовход доступен в Standalone, VST3 и AU.

- В Standalone выберите вход в Options → Audio/MIDI Settings и снимите Mute audio input,
  когда будете готовы слушать сигнал.
- В DAW направьте сигнал с аудиодорожки на вход инструмента Vocoder / external. Хост может
  показывать его как Side Chain.

Во всех форматах стереосигнал сводится в моно.

Поднимите уровень внешнего входа в настройках Mixer. Удерживайте MIDI-ноты, чтобы
пропустить вход через фильтр и огибающую. Direct to FX направляет вход в эффекты. Для
вокодера выберите Vocoder и сыграйте ноту. В KS Performance вокодер относится к первой
партии.
